# Team lanes

Fill in names tonight. The rubric gives Prototype and Business 25 points each, so both lanes need an owner, and the tiebreaker is Prototype first, then Business.

| Lane | Owner | Rubric criteria it feeds | Deliverable |
| --- | --- | --- | --- |
| Build core | | Core Functionality, Build Quality, Problem Solution Fit | Profiler, agent, and the live demo path working end to end |
| Safety and testing | | Testing and Limitations, Thoughtful Approach | Sensitivity rules, tests, a short list of known limits |
| Design and UI | | Usability and Accessibility | Clear plain language screens, readable contrast, obvious core action |
| Research and evidence | | Problem Definition, User Understanding, Evidence of Need | 5 to 8 conversations logged in docs/EVIDENCE_LOG.md |
| Business case | | Market Sizing, Revenue Model, Costs, Adoption and First Pilot, Roadmap | Bottom up sizing, unit economics, one named pilot |
| Pitch | | Clear Story and Evidence, Q and A and Assumptions | Five minute script, rehearsed with the demo inside the clock |

## Checkpoints

Saturday evening: the core action works on the sample data and one person other than the builder has tried it.
Saturday night: freeze scope. Anything not working gets labeled Simulated or Planned.
Sunday 9 a.m.: demo frozen, pitch rehearsed out loud with a timer.
Sunday 10 a.m.: preliminary pitches begin (5 minutes pitch plus demo, 4 minutes Q and A).
